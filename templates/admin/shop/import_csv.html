Инструкция по импорту

Процесс импорта:

  1. Загрузка файла - файл копируется на сервер и анализируется
  2. Анализ файла - автоматическое определение типа и подсчет записей
  3. Запуск импорта - после загрузки можно запустить парсинг

📊 DBF файлы (рекомендуется)

Формат: Стандартная база данных dBase

Кодировка: CP1251

Поля:

  • TMP_ID - Код товара
  • NAME - Наименование
  • PROPERTY_P - Производитель
  • PROPERTY_T - Каталожный номер
  • PROPERTY_A - Дополнительный номер
  • PROPERTY_M - Применяемость
  • PROPERTY_C - Кросс-код
  • SECTION_ID - Категория

📄 CSV файлы (устаревший)

Формат: CSV с разделителем (#)

Кодировка: Автоопределение

Поля (старый формат):

  • TMP_ID - Идентификатор в 1С
  • NAME - Наименование товара
  • PROPERTY_PRODUCER_ID - Производитель
  • PROPERTY_TMC_NUMBER - Номер ТМЦ
  • PROPERTY_ARTIKYL_NUMBER - Доп. номер
  • PROPERTY_MODEL_AVTO - Применяемость
  • PROPERTY_CROSS_NUMBER - Кросс-код
  • SECTION_ID - Номенклатурная группа

✅ Особенности:

  • Автоматическое создание категорий и производителей
  • Уникальные slug для каждого товара
  • Оптимизировано для больших файлов (200k+ записей)
  • Фоновый импорт с отслеживанием прогресса
  • Поддержка отмены импорта
